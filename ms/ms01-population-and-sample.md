**最值得记住的四句话：**
1. Survival analysis = time-to-event analysis，研究事件何时发生。
2. Censoring ≠ missing data to discard，即使没有观察到事件，仍然有部分信息。
3. Survival function \(S(t)\) 描述事件在 \(t\) 时刻之后才发生的概率。
4. Hazard function \(h(t)\) 描述仍处于风险中的个体在时刻 \(t\) 的瞬时事件发生率。
